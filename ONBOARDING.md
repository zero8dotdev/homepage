### Skills to Know About
- `/gws` — Google Workspace CLI (Gmail, Calendar, Drive). Used for inbox triage, sending email, calendar checks. Two profiles configured: `claude-workspace` (hello@zero8.dev, default) and `inboxstack` (juhy@inboxstack.com).
- `/copy-voice` — Apply the InboxStack writing voice to new pages or audit existing copy. Use when rewriting marketing/landing copy.
- `/design-system` — Apply the InboxStack homepage design system to new pages or audit existing ones against it.
- `/a11y-audit` — WCAG 2.1 AA audit + fixes for Svelte/SvelteKit pages.
- `/audit-blog` — SEO/GEO/perf/a11y scorecard for any URL.
- `/seo-geo` — SEO + Generative Engine Optimization for AI search visibility (ChatGPT, Perplexity, Gemini).
- `/zoho-bookkeeper` — Zoho Invoice bookkeeping for Zero8 Dot Dev Pvt Ltd (expenses, reconciliation, FY summaries).
- `/verify` — Run the app and observe behavior to confirm a change actually works (not just type-checks).
- `/ultrareview` — Multi-agent cloud review of the current branch or a PR. User-triggered, billed.
